# A spot on a thread

GOAL: A thread that names a spot shows that spot's name, a link to its forecast on the map and, if cheap, the current wind.
STATE: Spots: public/riding-locations.json (25). Per-point series on the map: src/usePointSeries.ts. VERIFIED: it imports no maplibre (only force5/src/weather and force5/src/timeline), but it lives in src/, which tests/bundle-isolation.test.ts keeps out of the community's graph, and the card does not need it: for a named spot it returns manifest.spotForecasts[id] (usePointSeries.ts:44), which weather/harmonie.json already carries for all 25. The map had no address for a spot before this item; it now reads /?spot=<id> (src/locations.ts spotFromSearch, src/App.tsx).
SPEC:
- S1 The card sits under the opening post: name, county, link to the map focused on the spot.
- S2 Wind reading (speed, direction, gust, now) only if the series loader imports cleanly into the community bundle with < 15 KB added. Otherwise ship S1 and record the finding in LOG.
- S3 The swatch colour is the wind ramp stop for the speed; the number stays in ink.
- S4 The API stores spot_id only and knows nothing about weather.
