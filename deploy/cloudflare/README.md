# The forecast on Cloudflare Containers

The same worker image and timetable as the Mac mini (`deploy/home-compute`) and
the Compose stack (`deploy/local`), on Cloudflare instead. This folder is
configuration only: nothing in the repo deploys it.

- `jobs.json` is generated by `deploy/schedules.py` from `deploy/local/jobs.toml`.
- `wrangler.jsonc` builds the image from `force5/Dockerfile` and wakes the Worker
  every five minutes.
- `src/index.ts` runs the jobs whose UTC slot it is, one Durable Object per job,
  so a job never overlaps itself. Each run gets the smallest instance that fits
  (`small` 1 vCPU/1 GiB, `medium` standard-1, `large` standard-3, `ensemble`
  2 vCPU/8 GiB/20 GB), and an alarm stops it after its importer's timeout.

## Deploy

Needs the Workers Paid plan, and Docker with the `buildx` plugin to build the image
(`brew install docker-buildx` on a Colima Mac).

```sh
cd deploy/cloudflare
npm install
npx wrangler login
for name in S3_BUCKET S3_ENDPOINT_URL AWS_ACCESS_KEY_ID AWS_SECRET_ACCESS_KEY; do
  npx wrangler secret put "$name"
done
npx wrangler secret put RUN_TOKEN     # optional: POST /run/<job> with this bearer token
npm run check                         # types and typecheck
npm run deploy
```

`GET /jobs` lists the timetable; each run logs `job_started` and `job_finished` /
`job_failed` (with the exit code) beside the importer's own JSON lines in Workers
Logs. Run the Mac mini or Cloudflare, not both: they would publish the same runs twice.

## Cost

Billed per second while a container runs: memory and disk for the instance's size,
CPU only while it works. With every importer skipping runs already published, most
slots last seconds; the estimate is $15-30 a month including the $5 plan.
